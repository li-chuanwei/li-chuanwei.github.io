# Chuanwei 个人主页

基于 Vite、React 与 TypeScript 构建的个人主页，用于展示个人笔记、近期作品与自我介绍。界面采用编辑型排版，并支持响应式布局、深浅色主题、站内内容搜索和减少动画偏好。

## 本地开发

```bash
pnpm.cmd install
pnpm.cmd dev
```

## 质量检查

```bash
pnpm.cmd lint
pnpm.cmd build
```

## 项目约定

- 图标统一使用 `reicon-react`。
- OpenSpec 已针对 Codex 初始化，配置位于 `openspec/config.yaml`。
- Windows 环境下统一使用 `.cmd` 执行包管理命令。
